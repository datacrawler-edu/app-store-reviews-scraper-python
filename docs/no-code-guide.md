# Collect and export reviews without code

1. Open the [App Store Reviews Scraper](https://apify.com/datascraperes/app-store-reviews-deep-scraper?fpr=edudata) in Apify.
2. Under **Input**, enter an app ID, bundle ID or App Store URL. Start with a single storefront and copy the [sample input](../data/sample-input.json) for a small run.
3. Set the review cap per app and storefront and the run-wide cap. Check the Actor Pricing tab before pressing **Start**.
4. Open the **Dataset** and download CSV or JSON. Open **Run summary** and check the selected app–storefront pair's stop reason.
